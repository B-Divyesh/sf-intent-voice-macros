      How it works

      Set each action boundary

      1. 01

        Name the action

        Add one phrase, one website, and one visible page control.

      2. 02

        Press, then speak

        The microphone starts after your press. You can type the phrase instead.

      3. 03

        Confirm risky actions

        Navigation, submit, delete, payment, publish, and sign-out actions pause first.

      4. 04

        Review the local log

        The extension keeps the latest 100 results in browser storage.

      Privacy and limits

      The extension follows your list

      • Exact phrases onlyA similar phrase does not run an action.
      • One approved siteA command does not follow you to another hostname.
      • Visible listeningListening starts only when you press the popup button.
      • Local recordsNo audio, analytics, or page content is stored.
