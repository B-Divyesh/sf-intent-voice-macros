Set it up once.
See every boundary.

  1. 01

    Name the action

    Add an exact phrase such as “focus search,” the website, and a CSS selector for the visible control.

  2. 02

    Press, then speak

    The microphone starts only after your press. A typed phrase always remains available.

  3. 03

    Confirm the risky ones

    Navigation, submit, delete, publish, payment, and sign-out controls pause and name what will happen.

  4. 04

    Check the local log

    See the last 100 attempts, including misses and cancellations. Audio is never saved.

Guardrails, not guesswork

It cannot improvise.

  • Exact phrases onlyNo chatbot and no fuzzy agent deciding what you meant.
  • Site-bound actionsA command for one hostname does not follow you elsewhere.
  • Visible listening stateThe popup must be open. No hidden background microphone.
  • Local recordsCommands and logs stay in browser storage. Export or clear them anytime.
